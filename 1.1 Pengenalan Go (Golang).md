# 1.1 Pengenalan Go (Golang)

## Tujuan Pembelajaran

* Memahami apa itu bahasa pemrograman Go.
* Mengenal sejarah dan latar belakang pembuatannya.
* Mengetahui keunggulan, kekurangan, dan ekosistem Go.
* Mengenal kegunaan nyata Go di dunia industri.

---

## Apa Itu Go?

Go (atau Golang) adalah bahasa pemrograman open-source yang dikembangkan oleh Google. Go dirancang agar mudah dipelajari, efisien, aman, dan cocok untuk sistem skala besar.

**Filosofi Go:**

* Sederhana dan efisien
* Kompilasi cepat
* Manajemen memori yang aman
* Dukungan concurrency bawaan (via goroutine dan channel)
* Cocok untuk membangun aplikasi backend, API, CLI, hingga microservices

---

## Kenapa Go Dibuat?

Go dibuat karena para engineer di Google merasa:

* C/C++ terlalu kompleks dan lambat dikompilasi.
* Java terlalu verbose dan berat.
* Python dinamis tapi tidak cocok untuk sistem skala besar.

**Go ingin menggabungkan:**

* Performa dan efisiensi seperti C
* Simplicity seperti Python
* Concurrency modern

---

## Keunggulan Go

| Keunggulan           | Penjelasan                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| ✅ Kompilasi Cepat    | Go memiliki compiler super cepat.                                      |
| ✅ Sintaks Sederhana  | Mudah dibaca, mirip C, tapi lebih bersih.                              |
| ✅ Garbage Collection | Tidak perlu manual allocate/deallocate memory.                         |
| ✅ Concurrency Bawaan | Goroutine dan channel membuat paralelisme menjadi mudah.               |
| ✅ Cross Compilation  | Bisa build ke berbagai OS dari satu mesin.                             |
| ✅ Statically Typed   | Mencegah banyak bug sejak awal.                                        |
| ✅ Tools Resmi Kuat   | Built-in formatter (`gofmt`), test framework, document generator, dll. |

---

## Kekurangan Go

| Kekurangan                          | Penjelasan                                              |
| ----------------------------------- | ------------------------------------------------------- |
| ❌ Tidak OOP penuh                   | Tidak ada inheritance, hanya interface dan composition. |
| ❌ Error handling verbose            | Tidak ada exception, hanya return `error`.              |
| ❌ Generics baru diperkenalkan       | Baru stabil sejak Go 1.18.                              |
| ❌ Kurang cocok untuk UI/Desktop app | Fokus utama untuk backend/server.                       |

## Proyek Nyata Menggunakan Go

Beberapa perusahaan dan proyek terkenal yang menggunakan Go:

* **Docker** – Platform containerisasi
* **Kubernetes** – Orkestrasi container
* **Terraform** – Infrastructure as Code (IaC)
* **Hugo** – Static site generator
* **Cloudflare**, **Uber**, **Twitch**, **Dropbox**, **Netflix**

---

## Kapan Go Digunakan?

Gunakan Go ketika kamu butuh:

* Aplikasi backend yang cepat dan stabil.
* Sistem skala besar yang membutuhkan concurrency tinggi.
* CLI tools dan automasi script yang efisien.
* API server yang ringan dan scalable.
