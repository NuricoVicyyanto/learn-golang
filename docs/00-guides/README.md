# Guides

Short, practical guides for using this curriculum well.

| Guide | Use it when... |
| --- | --- |
| [How to study](how-to-study.md) | You want a repeatable study routine |
| [Note conventions](note-conventions.md) | You are unsure how to name or format a file |
| [Definition of done](definition-of-done.md) | You want to know whether a module is really finished |
| [Topic note template](templates/topic-note.md) | You want to add a new topic |
| [Exercise log template](templates/exercise-log.md) | You want to record practice attempts |
| [Project brief template](templates/project-brief.md) | You are planning a capstone or side project |
| [Debug log template](templates/debug-log.md) | You are stuck on a bug and want to learn from it |

## The short version

1. Read the module README.
2. Fill one topic note per sitting, in your own words.
3. Type every example and change it.
4. Do the exercises without notes.
5. Build the mini project.
6. Run the self-assessment and update `PROGRESS.md`.

If you only remember one rule: **the notes are not the learning; the recall and the code are.**
