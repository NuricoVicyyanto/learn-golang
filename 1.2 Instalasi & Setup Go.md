# 1.2 Instalasi & Setup Go

## Tujuan Pembelajaran

* Menginstal Go di berbagai sistem operasi (Windows, macOS, Linux, dan Android melalui Termux).
* Men-setup `GOPATH`, `GOROOT`, dan struktur direktori Go.
* Menjalankan program Go pertama.

---

## Langkah Instalasi

### 🔹 1. Download Go

Kunjungi situs resmi: [https://go.dev/dl/](https://go.dev/dl/)

Pilih sesuai sistem operasi:

* **Windows**: `.msi` installer
* **macOS**: `.pkg` installer atau `brew`
* **Linux**: archive `.tar.gz`
* **Android (Termux)**: melalui `pkg` command

### 🔹 2. Instalasi di Windows

1. Unduh dan jalankan installer `.msi`
2. Ikuti wizard instalasi sampai selesai
3. Secara otomatis akan mengatur `GOROOT` dan path environment
4. Buka Command Prompt dan cek instalasi:

```bash
go version
go env
```

### 🔹 3. Instalasi di macOS

#### Menggunakan Homebrew (direkomendasikan):

```bash
brew install go
```

#### Atau manual dari `.pkg`:

1. Unduh `.pkg` dari [https://go.dev/dl/](https://go.dev/dl/)
2. Jalankan dan ikuti wizard instalasi
3. Tambahkan PATH jika perlu:

```bash
export PATH=$PATH:/usr/local/go/bin
```

Cek instalasi:

```bash
go version
```

### 🔹 4. Instalasi di Linux (Ubuntu/Debian/Arch/Fedora)

#### Manual (direkomendasikan untuk semua distro):

```bash
wget https://go.dev/dl/go1.21.x.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.21.x.linux-amd64.tar.gz
```

Tambahkan ke PATH:

```bash
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
```

#### Alternatif (Ubuntu/Debian):

```bash
sudo apt update
sudo apt install golang-go
```

#### Alternatif (Arch):

```bash
sudo pacman -S go
```

#### Alternatif (Fedora):

```bash
sudo dnf install golang
```

### 🔹 5. Instalasi di Android via Termux

1. Install Termux dari F-Droid (bukan Play Store)
2. Jalankan perintah berikut:

```bash
pkg update && pkg upgrade
pkg install golang
```

3. Cek versi Go:

```bash
go version
```

## Konfigurasi Environment

### GOROOT vs GOPATH

* `GOROOT`: Lokasi instalasi Go (default: `/usr/local/go`)
* `GOPATH`: Lokasi workspace proyek kamu (default: `$HOME/go`)

Cek environment:

```bash
go env GOROOT
go env GOPATH
```

Struktur direktori:

```
$GOPATH/
├── bin/
├── pkg/
└── src/
```

Pastikan kamu menambahkan PATH `bin` dari `$GOPATH` juga:

```bash
echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc
source ~/.bashrc
```

## Menjalankan Program Pertama

### 1. Buat File `hello.go`

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

### 2. Jalankan

```bash
go run hello.go
```

### 3. Compile

```bash
go build hello.go
```

Akan menghasilkan file binary `hello`.

---

## Tips Tambahan

* Gunakan `go fmt` untuk format kode:

```bash
go fmt hello.go
```

* Cek dokumentasi:

```bash
go doc fmt.Println
```

* Periksa versi:

```bash
go version
```

## Troubleshooting Umum

| Masalah                       | Solusi                                                               |
| ----------------------------- | -------------------------------------------------------------------- |
| `command not found: go`       | Cek PATH sudah benar.                                                |
| `go: cannot find main module` | Pastikan file berada dalam folder proyek atau gunakan `go mod init`. |
| Error permission              | Jalankan terminal sebagai admin/sudo.                                |
